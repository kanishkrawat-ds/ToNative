How to read the delta

Each row compares one token in Set A against the same token in Set B. The tag on the right tells you how different the two colors are — and whether a human eye would catch it.

ΔE — overall difference

Delta-E (CIEDE2000) rolls lightness, hue and saturation into one perceptual score. It answers “should I care?”

ΔEWhat you seeTag
< 2Invisible / near-identicalMatch
2 – 5Noticeable at a glanceNoticeable
≥ 5Clearly different colorsSignificant

Lum — brightness difference

How much lighter or darker Set B is vs Set A (relative luminance, %). − = darker, + = lighter. This is the “one looks dimmer” axis.

Hue — color-wheel shift

How far the color rotated around the wheel (0–180°). Small = a tint shift (green → teal); large = a different color family.

Base palette dot

Next to each Base name, a dot shows which primitive palette the value resolved from: Base.Colour (British) · Base.Color (American). Hover the dot for the full primitive path.

Worked examples

ΔE ≈ 1.5 · Match. Same green, a hair darker. Eye won’t catch it → no action.
ΔE ≈ 4 · Noticeable. A slightly deeper grey. A careful eye spots it → review.
ΔE 10.9 · Lum −8% · Hue 7°. Mostly a big brightness drop plus a slight tint turn — obviously different → fix.

Rule of thumb: ΔE = the flag · Lum = is it a brightness problem · Hue = is it a tint problem.
